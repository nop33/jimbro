# Gymtime

Gymtime is the live workout. The page opens on the program's exercises, and the first change the user makes starts the workout. The user logs sets on each exercise card, rests on the break timer, and edits, removes or reviews sets.

## Sub-features

- `gymtime-form` is `#workout-details`, collapsed, whose summary line (`Workout details`) shows the day (`#workout-date-label`: `Today`, `Yesterday` or `Oct 11`) and gym (`#workout-gym-label`, `No gym` when empty). Open, it has date (today at most), Gym (suggestions from gyms already used, prefilled from the latest workout, `Clear gym` button) and Notes. It has no submit: before the start the fields say what the start stores, and after it each change saves when the field is left.
- `gymtime-start` is the first change on the page: logging a set, `Add set`, removing a set to do, a menu action or adding an exercise. On a workout dated today it first opens the `Start your watch` sheet (`#watch-reminder-dialog`): `Start workout` goes on, ticking `Don't remind me again` first turns the reminder off until Settings' `Watch reminder` switch turns it back on, and its grabber, a pull down or a backdrop tap saves nothing. A workout dated another day starts without asking. It creates the workout with the form's day, gym and notes, shows the toast `Workout started · <time>` (after the change's effects, so it shows above the break timer a first set opens), moves the URL to `?id=` and shows the header's `Delete`. Opening a program and leaving saves nothing.
- `gymtime-progress` is `#workout-progress` over the cards: `N of M exercises`, `N of M sets` and a `<progress>` bar (`Sets logged`) of the sets, which shows the plan at zero before the start.
- `gymtime-cards` shows one card per exercise: name with its muscle badge (and a kind badge for rehab) and `⋯` on the first row, then `.exercise-open-btn` on the second (a segment per set, so every card's segments line up, `.isLogged` once logged, `N/M`, `Next <set>` until done; named `<name>: N of M sets, next <set>`). A tap anywhere on the card opens its `dialog.exercise-sheet`, a bottom sheet titled with the exercise. Its body holds `Previous sets` and `View History` in a row on top, then set rows (`.set.isCompleted` logged, `.isPending` target), `Add set` (muted grey, like a set still to do, on the right under the last set), and its footer, pinned to the sheet's foot while the body scrolls, the next-set form with `Finished set` (and a `Max` pill on a weight prefilled with last time's heaviest, and on reps prefilled with last time's most at that weight). `Previous sets` shows only when an earlier workout logged the exercise and `View History` not for cardio; the row goes when neither does.
- `gymtime-finish-set-grow`: holding `Finished set` (`.finish-set-btn`) for about half a second grows it to half the screen (`#exercises-list.finish-set-grown`, `min-height: 50dvh`, centred on screen once grown) so a shaky hand can't miss it. It stays grown set after set and on every card, and only another hold on it shrinks it back. A hold's release logs nothing; a tap logs the set either way. It shows no iOS callout, text selection or Android context menu, and grows at once under reduced motion. `tests/gymtime.spec.ts` covers it.
- `gymtime-menu` is each card's `Actions for <name>` popover: Move up, Move down, Swap exercise, Delete exercise. Move buttons hide at the ends. Swap and Delete hide on a finished exercise and ask a confirm.
- A set logged from the card first draws its border: an `svg.set-trace` stroke runs around the new `.set.isCompleted` row, and the break timer, the card's close and the celebrations wait for it. The tour runs with reduced motion, which skips it, so it shows in no stop.
- `gymtime-break` opens `#break-countdown-dialog` after a lifting or cardio set that does not finish its exercise, a bottom sheet that slides up and covers the whole screen, with a grabber at its top: `#sets-done`, `#countdown`, `Coming up`, `Minimize` (a caret pointing down, to the bar), `View exercise history`, `Skip`. Pulling the full timer down minimizes it too, once pulled past a fifth of the screen (at most 120px) or flicked; a shorter pull slides back. The bar shows an `Expand` caret on its right, and a tap on it or anywhere on the bar opens the full timer. `28-break-timer-minimized` pulls it down. It shows 0:00 for a second and then closes itself, so it never counts below 0:00. Rehab sets never open it. The timer outlives the page: on any page the router shows next, the minimized bar keeps counting and a tap opens the full timer there, with `Back to workout` (`#back-to-workout`, to the workout with the bar) in place of `View exercise history`, which needs gymtime.
- `gymtime-break-alerts`: where the browser has push (the iPhone's Home Screen app, Chrome), the full timer has `Break alerts`, a bell at the top right with `aria-pressed`, struck through while off, which shows a spinner in place of the bell (`aria-busy`) while turning alerts on or off waits for the browser and the worker, and a `role="status"` line under it (`Break alerts on.`, `Break alerts off.`, or why not: no cloud backup, blocked, not set up). While alerts are off and the device backs up, the bell is highlighted (accent ring, a pulse outside reduced motion) and `#break-alerts-tip`, a speech bubble under it, says `Tap the bell to get a notification when the break ends, even with the phone locked.` with `Not now` (14 days; turning off with the bell hides it for a year). No tour browser reaches a push service, so `tests/breakAlerts.spec.ts` covers it with a stand-in subscription.
- `gymtime-set-menu` opens the card's `.set-menu` popover from a set to do (`Set N, to do`), with `Remove set N`, which asks `Remove set N?` and removes one set to do on OK. The rows are buttons only while more than one set is left to do and more than the sets logged, so an exercise keeps at least one set. A tap outside the set menu, the actions menu or a badge popover only closes it: the row, set or button under the tap does not react (`tapToDismiss.ts`).
- `gymtime-edit-set` opens `#edit-set-dialog` from a logged set, focusing its title rather than a field. Saving shows `Set updated.`. A 0 value asks a confirm. `Delete`, on the left of `Save` (there is no `Cancel`, closing the sheet cancels), confirms, shows `Set deleted.` and leaves the slot to do again.
- `gymtime-previous` opens `#last-set-dialog` (`Previous sets`) on last time: the day and gym (`#last-set-date`, `#last-set-gym`) between `Older workout` and `Newer workout` arrows, which step through every earlier workout that logged the exercise, at any gym, and turn off at either end. The left and right arrow keys step too. Newer stops at the most recent earlier workout, never the open one.
- `gymtime-history` opens `#exercise-history-dialog`: a chart with toggles `Average weight`, `Estimated 1RM`, `Total volume`, and gym bands with a legend in `#exercise-history-gyms`.
- `gymtime-add` opens the exercise picker, `dialog#exercise-picker` (the sheet `program-add` describes in `programs.md`), from `#add-exercise-card`, titled `Add exercises`. The workout's exercises show ticked, greyed and disabled, with `In workout`, and the ticked ones join the workout's end in the order ticked, the first starting the workout. Swap opens the same sheet titled `Swap exercise`, with a button per exercise instead of a checkbox and no footer: a tap swaps.
- `gymtime-save-to-program` shows `#save-to-program-card` when the workout's exercises differ from the program's. It saves with the toast `Saved to program`.
- `gymtime-sheet` is not modal, so the minimized break timer's bar stays on top of it and takes taps; while the bar shows, the sheet sits above it. A tap outside it only closes it. It stays open from set to set and while the timer is minimized, and closes when pulled down, on its grabber (`Close dialog`), on Esc, or on the set that finishes the exercise.
- `gymtime-done` bursts confetti from the card's corner with `Exercise done!` when an exercise's last set is logged, and stamps `Workout done!` with rings and sparks when the workout's is, then downloads a JSON export when cloud backup is off. The `.confetti` layer is a popover that leaves once its animations end, a few seconds later.
- `gymtime-passkey-offer` is the `Back up your workouts` card (`#passkey-offer`, a region, not a dialog) under the exercises after `Workout done!`, where the browser has passkeys and no passkey backs the phone up. `Create passkey` signs up and shows `Passkey created. Your workouts are backing up.`. `Already have a passkey? Sign in` confirms when the phone holds data, signs in, shows `Signed in. Restoring your workouts.` and loads the page again after the sync. `Not now` hides it for 14 days.
- `gymtime-delete` is the header's `Delete`, shown once the workout has started. It confirms, shows `Workout session deleted` and returns to `/workouts/`.
- `gymtime-error` shows `Could not load workout. The program or session may no longer exist.` and `Back to workouts` for a missing or unknown `programId` or `id`, with no `Delete` in the header.

## How to get to it (user POV)

- Choose a suggested pick on Home.
- Choose a program in the Workouts page's New workout dialog, or a workout day on its calendar.
- Choose an incomplete or completed card on Workouts to resume or view it (`?id=`).

## Driving it with control-jimbro

Preconditions: `control-jimbro doctor` passes. The tour imports a year of history first, so `Previous sets`, the history chart and gym suggestions have data.

- **Tour stops.** `22-gymtime-new` (summary line, cards before the start), `23-gymtime-details` (the details open), `24-gymtime-started` (Add set, then `Start workout` on the watch reminder, started it), `25-gymtime-card-open` (the first card's sheet), `26-gymtime-set-menu`, `27-break-timer`, `28-break-timer-minimized`, `29-edit-set-dialog`, `30-previous-sets-dialog` (last time, Newer off), `31-previous-sets-older` (one workout back, both arrows on), `32-history-chart-dialog`, `33-gymtime-card-menu` (the sheet closed first), `34-add-exercise-dialog`, `35-gymtime-passkey-offer` (deletes all but the first exercise and logs its sets until `Workout done!`), `41-gymtime-error`, `42-break-timer-other-page` (a set logged, the timer minimized, then Exercises from the nav: the bar stays and keeps counting), `43-break-timer-off-gymtime` (the bar tapped there: the full timer offers Back to workout instead of the history chart), `44-gymtime-finish-set-grown` (Finished set held on the first card of a workout not yet started), `45-gymtime-watch-reminder` (Add set on a workout not yet started: the `Start your watch` sheet).
- **By hand: a logged set persists.** After logging, reload the `?id=` URL and open the card's sheet. The `.set.isCompleted` row still shows the values.
- **By hand: cardio and rehab.** Create a cardio or rehab exercise on `/exercises/`, add it with `#add-exercise-card` (its chip, `Cardio` or `Rehab`, finds it), and open its sheet. Cardio has `set-durationSec`, `set-speed` and `set-incline` inputs and no `View History`. A rehab set opens no break timer.

## Gotchas

- Open gymtime from Workouts or Home. `/gymtime/` with no `programId` or `id` is the error state.
- Only `.set.isCompleted` opens the edit dialog. An `.isPending` row opens the set menu, when it can be removed.
- The break timer closes itself after its countdown, so a slow step can miss `Skip`. The tour minimizes it instead.
- Completing every set of a workout downloads a JSON file. Handle the download, or log fewer sets.
- The passkey offer's `Create passkey` needs a passkey the browser can make: WebAuthn refuses the IP address origin `127.0.0.1`, and the verification server's API is dead. The tour only shows the card here, and signs up on `localhost` in `36-settings-passkey`.
- After the start, keep using the `?id=` URL. Opening the same `programId` again and changing anything starts another workout.
- Never force a click. A click that needs force means something covers the control, which is a finding.
